    Add a game

    Every game is a folder in the catalog with a game.json that lists its versions and where to download each one. To add one:

    1. Create the entry: python main.py new-game "My Game"
    2. Add an icon.png and cover.jpg to its folder, and its versions to game.json. catalog/README.md has copy-paste examples for GitHub releases, source code, direct links and files on this computer.
    3. Check it: python main.py check
    4. Press the reload button at the top right. The game appears in the library.
    1. Open your catalog folder (button below) and make a folder for the game, named like my-game.
    2. Put a game.json in it, with an icon.png and cover.jpg. catalog/README.md in the Toki-Hub repository explains the format, with copy-paste examples.
    3. Press the reload button at the top right. Any mistakes show up as catalog problems in the library.

    Games added to the catalog folder of the Toki-Hub repository are built into the next Toki Hub release instead, for every copy of the hub.

    New versions of an existing game work the same way: add an entry to its versions list.
