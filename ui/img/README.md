# Toki's portrait

The dialogue bar at the bottom of the hub shows `toki-emblem.svg` (an original badge: bunny ears, a halo
and her call sign, 04).

To show a picture of Toki instead, save it here as **`toki.png`**. Any square-ish image works. It is
cropped to a circle, so a head-and-shoulders shot looks best. Restart the hub or reload the page to see it.

`toki.png` is listed in `.gitignore`, so a picture you don't own the rights to stays on your computer
and is never pushed to GitHub. Remove that line if you want to commit it.
